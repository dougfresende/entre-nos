## Design Context

### Users
Convidados de um casamento acessam o aplicativo no próprio celular durante e depois da celebração. Eles precisam entrar rapidamente por NFC ou QR Code, registrar fotos, vídeos e recados, cumprir missões e rever o álbum. Os noivos e a equipe de organização também precisam de controles administrativos em uma etapa posterior.

### Brand Personality
Editorial, acolhedora e serena. A linguagem é direta e calorosa, sem excesso de celebração artificial. O produto deve passar a sensação de um convite bem impresso que ganha vida no celular.

### Aesthetic Direction
Direção aprovada: marfim, verde-oliva e fotografia espontânea. Cormorant Garamond atende títulos e momentos editoriais; DM Sans atende controles e leitura de interface. A referência formal é `outputs/design-system/`; a navegação deve ser clara, com uma ação principal por contexto e controles de 48 px.

### Implementation Defaults
Não há stack existente. Para o novo projeto, usar Vite + React + TypeScript, Tailwind CSS e componentes próprios guiados pelo Design System 1.0. Adotar APIs nativas primeiro; quando a complexidade justificar, usar TanStack Form para formulários, TanStack Table para administração e TanStack Virtual para acervos longos. Base UI é a preferência para eventuais primitivas headless. Estas escolhas vêm do fallback do projeto, não de preferência explícita do usuário.

### Design Principles
1. Dar espaço à fotografia; a interface orienta sem disputar atenção.
2. Estabelecer hierarquia com tipografia, contraste e respiro antes de usar cor.
3. Manter uma ação principal por contexto e feedback honesto para envio, falha e processamento.
4. Preservar acesso equivalente por NFC e QR Code: ambos levam ao mesmo destino.
5. Construir para telas pequenas primeiro, com foco visível, contraste e rótulos claros.
