# Entre Nós — aplicativo

Primeira interface do convidado para o projeto Entre Nós. Ela implementa a navegação inicial, álbum ilustrativo, missões, recados e seleção local de mídias, seguindo o Design System 1.0 em `../outputs/design-system`.

## Executar

```bash
npm install
npm run dev
```

## Limite atual

Esta etapa é apenas frontend: não há autenticação, NFC/QR real, banco de dados, upload persistente ou painel de organização. O botão de mídia usa o seletor local do navegador e informa que a conexão será feita depois.
