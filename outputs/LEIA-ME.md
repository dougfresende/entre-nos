# Pacote de handoff — Entre Nós

Para o Design System, abra `design-system/index.html` no navegador. Mantenha a estrutura das pastas ao extrair o ZIP: fontes e estilos funcionam offline. Leia `design-system/DESIGN-SYSTEM.md` para implementar. Para continuar o projeto, comece por HANDOFF.md e depois leia plano-entre-nos-nfc.md.

Decisão atual: NFC como acesso principal e QR Code como alternativa para quem não tiver NFC. Ambos devem conter a mesma URL do evento/mesa, sem necessidade de digitar.

Arquivos:
- design-system/ — guia visual interativo, documentação, tokens CSS/JSON, componentes CSS, ícones SVG, fontes com licenças e relatório de validação.
- HANDOFF.md — contexto para continuidade.
- plano-entre-nos-nfc.md — plano atualizado, arquitetura e testes.
- conceito-entre-nos.png — conceito visual original; o cartão ilustrado ainda não mostra o QR alternativo, incluído posteriormente no plano. Não é arte final para impressão.
- inventario-skills.md — levantamento de skills, com versões em cache.
- inventario-conectores.md — levantamento das ferramentas expostas.

O aplicativo não foi implementado nem publicado. Não há QR funcional gerado: depende de domínio e token reais. Nenhuma alteração de infraestrutura foi realizada.
